## 安装 Harbor {#install-harbor}

使用 Python（编程语言） 包管理器安装 Harbor。

<Tabs>
  <Tab title="uv">
    首先，[安装 uv](https://docs.astral.sh/uv/getting-started/installation/)。

    ```bash
    uv tool install harbor
    ```
  </Tab>

  <Tab title="pip">
    ```bash
    pip install harbor
    ```
  </Tab>

  <Tab title="升级 uv 安装的版本">
    ```bash
    uv tool uninstall harbor
    uv tool install harbor
    ```
  </Tab>
</Tabs>

## Nightly 构建（大多数用户很少使用） {#nightly-builds-not-frequently-used-for-most-users}

我们每天从最新的 `main` 分支构建一个 [开发版](https://pypi.org/project/harbor/#history)，并发布到 [PyPI（Python 软件包索引）](https://pypi.org/project/harbor/)。使用预发布标志安装（不会影响稳定版安装）：

<Tabs>
  <Tab title="uv">
    ```bash
    uv tool install --prerelease explicit 'harbor>=0.dev0'
    ```
  </Tab>

  <Tab title="pip">
    ```bash
    pip install --pre harbor
    ```
  </Tab>

  <Tab title="升级 uv 安装的版本">
    ```bash
    uv tool uninstall harbor
    uv tool install --prerelease explicit 'harbor>=0.dev0'
    ```
  </Tab>
</Tabs>

## 配置 Sandbox（沙箱） {#configure-a-sandbox}

Harbor 会在 Sandbox（沙箱）中运行 Agent（智能体）。默认情况下，Harbor 使用 [Docker（容器平台）](https://www.docker.com/)（容器平台）作为沙箱运行时，因此你需要先在计算机上[安装 Docker](https://docs.docker.com/get-started/get-docker/)。

不过，许多用户发现使用云沙箱效率更高。有关开箱即用的云沙箱选项，请参阅[预集成沙箱](/sandboxes/pre-integrated-sandboxes)。

使用非 Docker 沙箱时，需要安装额外依赖。例如：

<Tabs>
  <Tab title="uv">
    ```bash
    uv tool install "harbor[modal]"
    ```
  </Tab>

  <Tab title="pip">
    ```bash
    pip install "harbor[modal]"
    ```
  </Tab>
</Tabs>
