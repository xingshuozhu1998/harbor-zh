## 步骤 0：安装 Harbor {#step-0%3A-install-harbor}

按照[安装说明](/getting-started/installation)安装 Harbor（智能体评测框架），包括安装软件包及其依赖项。

## 步骤 1：创建 Task {#step-1%3A-create-your-task}

安装 Harbor 后，运行以下命令创建 Task 目录及其必需文件：

```bash
harbor task init ssh-key-pair
```

这会生成如下结构的 Task 目录：

```bash
ssh-key-pair/
├── instruction.md         # Task instructions
├── task.toml              # Configuration and metadata
├── environment/
│   └── Dockerfile         # Container definition
├── solution/
│   └── solve.sh           # Solution script
└── tests/
    │── test_outputs.py    # Pytest unit tests
    └── test.sh            # Test verification script
```

## 步骤 2：编写 Task 指令 {#step-2%3A-write-the-task-instructions}

打开 Task 目录中的 `instruction.md` 文件并添加 Task 描述：

```markdown title="ssh-key-pair/instruction.md"
# SSH Key Pair Generation

Generate an SSH key pair in the files `~/.ssh/id_rsa` and `~/.ssh/id_rsa.pub`.

Don't make them password protected.
```

## 步骤 3：配置 Task 元数据 {#step-3%3A-configure-task-metadata}

打开 `task.toml` 文件并配置 Task 元数据：

```toml title="ssh-key-pair/task.toml"
version = "1.0"

[metadata]
author_name = "Your Name"
author_email = "your.email@example.com"
difficulty_explanation = "Simple SSH key generation command"
category = "system-administration"
tags = ["ssh", "cryptography", "linux"]

[verifier]
timeout_sec = 120.0

[agent]
timeout_sec = 120.0

[environment]
build_timeout_sec = 600.0
```

在此处添加 `os = "windows"` 可针对 Windows（微软操作系统） 容器；默认值为 `"linux"`。如果 Task 需要显式资源，请添加 `cpus`、`memory_mb`、`storage_mb` 或 `gpus`。

## 步骤 4：创建 Task 环境 {#step-4%3A-create-the-task-environment}

打开生成的 `environment/` 目录中的 Dockerfile：

```dockerfile title="ssh-key-pair/environment/Dockerfile"
FROM ubuntu:24.04

# Create working directory
WORKDIR /app

# Install openssh-client for the task
RUN apt-get update && apt-get install -y openssh-client && rm -rf /var/lib/apt/lists/*
```

此 Dockerfile 定义了 Agent（智能体） 将通过终端与之交互的环境。在此添加 Task 所需的依赖项。

## 步骤 5：验证解决方案思路 {#step-5%3A-test-your-solution-idea}

编写自动化解决方案前，先手动验证你的方法是否有效。以交互方式构建并运行容器：

```bash
harbor task start-env -p ssh-key-pair -e docker -a -i # or use daytona or modal
```

在容器中运行以下命令，确认无需交互输入即可完成 Task：

```bash
ssh-keygen -t rsa -f ~/.ssh/id_rsa -N ""
```

确认密钥已正确创建：

```bash
ls -l ~/.ssh/id_rsa*
```

你应当看到：

```
~/.ssh/
├── id_rsa      (-rw-------  600  private key)
└── id_rsa.pub  (-rw-r--r--  644  public key)
```

使用 `exit` 或 `Ctrl+D` 退出容器。

## 步骤 6：编写解决方案脚本 {#step-6%3A-write-the-solution-script}

使用上一步验证过的命令创建解决方案脚本。Oracle Agent 会运行此文件，以确认 Task 可解。

更新 `solution/solve.sh` 文件：

```bash title="ssh-key-pair/solution/solve.sh"
#!/bin/bash

ssh-keygen -t rsa -f ~/.ssh/id_rsa -N ""
```

确保脚本具有可执行权限：

```bash
chmod +x ssh-key-pair/solution/solve.sh
```

## 步骤 7：创建测试脚本 {#step-7%3A-create-the-test-script}

测试脚本用于验证 Agent 是否成功完成 Task。它必须在 `/logs/verifier/` 中生成奖励文件。此教程为简洁起见使用 pytest（Python 测试框架）；如果需要多项判定、加权评分或 LLM-as-a-judge 评分标准，可考虑使用 [Rewardkit（奖励验证工具库）](/rewardkit/quick-start)。

更新 `tests/test.sh` 文件：

```bash title="ssh-key-pair/tests/test.sh"
#!/bin/bash

apt-get update
apt-get install -y curl

curl -LsSf https://astral.sh/uv/0.9.5/install.sh | sh

source $HOME/.local/bin/env

# Run pytest tests
uvx \
  --python 3.12 \
  --with pytest==8.4.1 \
  pytest /tests/test_outputs.py

# Check exit code and write reward
if [ $? -eq 0 ]; then
  echo 1 > /logs/verifier/reward.txt
else
  echo 0 > /logs/verifier/reward.txt
fi
```

然后创建 Python（编程语言） 测试文件：

```python title="ssh-key-pair/tests/test_outputs.py"
import os
from pathlib import Path


def test_key_files_exist() -> None:
    """Test that both private and public key files exist."""
    private_key = Path.home() / ".ssh" / "id_rsa"
    public_key = Path.home() / ".ssh" / "id_rsa.pub"

    assert private_key.exists(), "Private key file does not exist"
    assert public_key.exists(), "Public key file does not exist"


def test_key_file_permissions() -> None:
    """Test that the key files have correct permissions."""
    private_key = Path.home() / ".ssh" / "id_rsa"
    public_key = Path.home() / ".ssh" / "id_rsa.pub"

    private_perms = oct(os.stat(private_key).st_mode)[-3:]
    public_perms = oct(os.stat(public_key).st_mode)[-3:]

    assert private_perms == "600", (
        f"Private key has incorrect permissions: {private_perms}"
    )
    assert public_perms == "644", (
        f"Public key has incorrect permissions: {public_perms}"
    )


def test_key_format() -> None:
    """Test that the public key has the correct RSA format."""
    public_key = Path.home() / ".ssh" / "id_rsa.pub"

    with open(public_key, 'r') as f:
        content = f.read()

    assert content.startswith("ssh-rsa "), "Public key does not start with 'ssh-rsa'"
    assert len(content.split()) >= 2, "Public key format is invalid"
```

## 步骤 8：使用 Oracle Agent 测试 Task {#step-8%3A-test-your-task-with-the-oracle-agent}

运行以下命令，验证解决方案脚本能否完成 Task：

```bash
harbor run -p ssh-key-pair -a oracle
```

如果成功，输出会显示 Task 已完成且奖励为 1。

<Callout type="info" title="故障排除">
  如果 Oracle Agent 运行失败，请检查：

  * 解决方案脚本具有执行权限
  * Dockerfile 安装了所有必需依赖
  * 测试脚本正确写入 `/logs/verifier/reward.txt`
  * 测试中的路径与解决方案中的路径一致
</Callout>

## 步骤 9（可选）：使用真实 Agent 测试 {#step-9-optional-%3A-test-with-a-real-agent}

使用实际 AI Agent 测试 Task，观察它能否完成任务。例如，使用 Haiku 运行 Claude Code（Anthropic 编程智能体）：

```bash
harbor run \
  -p ssh-key-pair \
  -a claude-code \
  -m anthropic/claude-haiku-4-5
```

## 步骤 10（可选）：在查看器中检查输出 {#step-10-optional-%3A-inspect-the-output-in-the-viewer}

启动查看器，浏览本次运行的轨迹、Verifier（验证器） 日志和工件：

```bash
harbor view ./jobs
```

打开最新的 Job（任务运行集合），选择 `ssh-key-pair` Trial（单次运行），然后查看 **Verifier Logs** 标签页中的 pytest 输出和最终奖励。**Trajectory** 标签页会展示 Agent 执行的每一步，这对调试真实 Agent 失败的原因很有帮助。

## 步骤 11：庆祝 {#step-11%3A-celebrate}

恭喜！你已创建第一个 Harbor Task，现在可以用它评测 AI Agent 了！
