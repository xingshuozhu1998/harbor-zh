## 隐式数据集 {#implicit-datasets}

创建数据集最简单的方式，是将一组 Task（任务）放在同一个目录中。

```bash
my-dataset/
├── task1/
├── task2/
└── task3/
```

可以使用以下命令运行：

```bash
harbor run -p ./my-dataset -a "<agent>" -m "<model>"
```

## 显式数据集 {#explicit-datasets}

你可能需要定义多个包含部分相同任务的数据集。例如，可以将一个目录中的任务视为隐式数据集，再按类别划分子集。

这种情况下，复制粘贴任务既不方便也低效，还会增加维护成本。

可以改为创建 `dataset.toml` 清单，其中记录任务目录的位置。

### 创建 `dataset.toml` 清单 {#create-a-dataset-toml-manifest}

运行以下命令创建 `dataset.toml` 清单：

```bash
harbor dataset init "<org/name>"
```

该命令会在当前目录生成 `dataset.toml` 清单。

<Note>
通常，`<org>` 是公司名称，`<name>` 是数据集名称。
</Note>

### 添加和移除任务 {#add-and-remove-tasks}

运行以下命令将任务添加到数据集：

```bash
harbor dataset add "<task-dir>"
```

运行以下命令从数据集中移除任务：

```bash
harbor dataset remove "<task-dir>"
```

你也可以添加或移除另一个数据集中的所有任务：

```bash
harbor dataset add "<other-dataset.toml>"
harbor dataset remove "<other-dataset.toml>"
```

### 运行 `dataset.toml` {#run-the-dataset-toml}

运行 `dataset.toml` 清单：

```bash
harbor run -p "<path-to-dataset.toml>"
```

## 发布数据集 {#publish-a-dataset}

运行以下命令，通过 Harbor Hub（Harbor 的数据集注册与分发服务）与团队成员或公众共享数据集：

```bash
harbor publish "<org/name>"
```

可以把 Harbor Hub 理解为类似 PyPI（Python 软件包索引） 或 NPM 的软件包注册服务。任务属于软件，因此通常在版本控制仓库中开发，再将各个版本发布到 Harbor Hub。

发布数据集后，所有有权限的人都可以使用 `harbor run -d <org/name>` 命令运行它。
