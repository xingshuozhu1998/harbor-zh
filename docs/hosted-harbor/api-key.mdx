要通过 [CLI（命令行界面）](/hosted-harbor/cli) 或 [API](/hosted-harbor/api) 验证任何命令，必须先创建 Harbor（智能体评测框架） API 密钥。

## CLI {#cli}

使用 CLI 时，成功运行 `harbor auth login` 后会自动生成 API 密钥。
该密钥存储在 `~/.harbor/credentials.json` 中，并会在运行 `harbor auth logout` 后撤销。
你也可以通过 `HARBOR_API_KEY` 环境变量验证 CLI。下一节将介绍如何通过 Web UI（用户界面） 创建 API 密钥。

## Web UI {#web-ui}

如需在 Web UI 中生成 API 密钥，请先前往 [Harbor Hub](https://hub.harborframework.com)。

点击右上角的个人资料：
