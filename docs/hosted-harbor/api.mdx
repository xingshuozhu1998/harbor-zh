Web UI（用户界面） 和 CLI（命令行界面） 中的大部分启动功能也可以通过 API 使用。

所有端点的基础 URL 为：

```text
https://ofhuhcpkvzjlejydnvyd.supabase.co/functions/v1
```

## 身份验证 {#authentication}

每个请求都必须通过 Bearer token 发送 Harbor（智能体评测框架） API 密钥。如何创建密钥，请参阅 [Harbor Hub（任务与结果共享平台） API 密钥](/hosted-harbor/api-key)。

```http
Authorization: Bearer sk-harbor-...
Content-Type: application/json
```

## 错误 {#errors}

所有错误都采用相同结构：

```json
{
  "error": {
    "code": "validation_failed",
    "message": "config must contain at least one agent"
  }
}
```

| 代码 | 状态码 | 含义 |
| --- | --- | --- |
| `bad_request` | 400 | 请求格式错误，或缺少 `Idempotency-Key`、其长度超出限制 |
| `validation_failed` | 400 | 请求正文解析成功，但不符合架构或服务器端规则 |
| `unauthorized` | 401 | 缺少或提供了无效的 API 密钥 |
| `forbidden` | 403 | 未获准使用远程 Rollout，或不是所选组织的成员 |
| `not_found` | 404 | 作业不存在或对你不可见 |
| `method_not_allowed` | 405 | 此路径不支持该 HTTP（超文本传输协议） 方法 |
| `replacement_required` | 409 | 已存在具有此身份的凭据；请确认是否替换 |
| `replacement_stale` | 409 | 确认期间凭据已更改；请重新读取后重试 |
| `quota_exceeded` | 429 | 超出托管服务配额 |
| `server_error` | 500 | 内部错误 |
| `agent_version_resolution_failed` | 503 | 无法解析最新智能体版本；请重试 |
