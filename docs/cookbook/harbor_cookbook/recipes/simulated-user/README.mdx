此示例实现了包含模拟用户的任务，智能体可以与用户交互并提问。

## 目录结构

```
simulated-user/
├── README.md
├── task.toml                  # MCP server declared under [[environment.mcp_servers]]
├── instruction.md             # Tells the agent to talk to the user
├── environment/
│   ├── Dockerfile             # Agent container
│   ├── docker-compose.yaml    # Adds user-server service alongside main
│   └── user-server/           # Simulated user (FastMCP, streamable-http)
│       ├── Dockerfile
│       ├── server.py
│       └── persona.md         # User persona and requirements
├── tests/
│   ├── test.sh                # Verifier entrypoint
│   └── test_outputs.py        # Checks output and that ask_user was called
└── solution/
    └── solve.sh               # Reference solution
```

## 工作原理

MCP（模型上下文协议） 服务器（`environment/user-server/server.py`）提供单个 `ask_user` 工具。persona 文件（`persona.md`）定义模拟用户的身份。

智能体事先并不知道要构建什么；它必须调用 `ask_user` 了解需求，然后实现解决方案。测试会验证输出是否正确。

若要创建使用不同模拟用户的新任务，请复制此示例并替换 `persona.md`；`server.py` 无需修改。

## 环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 是 | 模拟用户调用 LLM 所需的 API（应用程序接口） 密钥 |
| `SIM_USER_MODEL` | 否 | 模拟用户使用的 Anthropic（模型服务提供商） 模型（默认值：`claude-sonnet-4-6`） |

## 运行

```bash
harbor run -p harbor_cookbook/recipes/simulated-user --agent claude-code --model anthropic/claude-sonnet-4-6
```

## 限制

多容器任务依赖 Docker Compose（多容器编排工具） 网络，因此需要 **docker** 环境 provider。Harbor（智能体评测框架） 的部分云 provider（Modal（云计算与沙箱平台）、E2B（云沙箱平台） 等）不支持这些任务。
