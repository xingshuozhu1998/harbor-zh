Harbor（智能体评测框架）会收集有限的使用遥测数据，以提升可靠性并确定开发优先级。默认启用此功能。

## 收集的数据 {#collected-data}

Harbor 会发送以下四类事件：

| 事件 | 数据 |
| --- | --- |
| `harbor.command_finished` | 运行时和平台、安装与启动来源、检测到的 AI 智能体标签、命令路径、参数名称、结果、耗时和作业 ID |
| `harbor.job_finished` | 作业 ID、智能体和模型、环境与资源、任务和 Trial（单次运行） 数量、启用的功能、公开来源、结果、令牌用量、成本、耗时和奖励 |
| `harbor.server_job_finished` | 上述作业数据，以及客户端、重试和推理次数、并发利用率 |
| `harbor.server_usage` | 按客户端汇总的 API（应用程序接口） 用量、结果、耗时、并发、转发使用情况及其他作业用量 |

## 不会收集的数据 {#not-collected}

- 原始命令或作业配置
- 原始 HTTP（超文本传输协议） URL、请求正文、请求头或 SQL 查询
- 本地路径、私有仓库名称或自定义注册表位置
- 任务指令、提示词或本地任务名称
- 环境变量、智能体或环境 kwargs、MCP（模型上下文协议） 配置
- 产物路径
- 异常消息或回溯信息
- 用户名、电子邮件或账号身份信息

## 身份标识与传输 {#identity-and-delivery}

Harbor 会在用户配置目录中创建随机的安装 ID。服务器事件也会包含随机的服务器 ID 和服务器运行 ID。这些 ID 不会根据账号或机器身份生成。

事件由独立进程发送到 PostHog。发送失败的事件会被丢弃。个人资料和 GeoIP 处理均已禁用。

## 选择退出 {#opt-out}

```bash
HARBOR_TELEMETRY=off harbor run ...
```
