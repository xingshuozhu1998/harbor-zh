Harbor（智能体评测框架） 提供本地网页查看器，用于查看任务和 Trial 结果。

## 启动查看器 {#start-the-viewer}

将查看器指向任务目录：

```bash
harbor view jobs
```

Harbor 会使用 `8080` 到 `8089` 之间第一个可用端口，并显示查看器 URL。默认地址为 `http://127.0.0.1:8080`。

需要时可以指定其他结果目录或端口：

```bash
harbor view /path/to/jobs --port 9000
```

<Note>
  查看器打开期间，请保持该命令运行。
</Note>

## 键盘快捷键 {#keyboard-shortcuts}

| 视图 | 按键 |
| --- | --- |
| 任务和任务列表 | 使用 `j` / `k` 导航，按 `Enter` 打开，按 `Esc` 返回 |
| Trial | 使用 `←` / `→` 切换 Trial |
| Trial | 使用 `Shift` + `←` / `→` 切换任务 |
| Trial | 使用 `Alt`（macOS（苹果桌面操作系统） 上为 `Option`）+ `←` / `→` 切换标签页 |

## 从查看器启动任务 {#run-from-the-viewer}

点击左上角的 **New run**，无需编写 CLI（命令行界面） 命令即可配置并启动任务。也可以直接访问 http://127.0.0.1:8080/run。使用 `←`、`→` 加载上一个或下一个任务配置。
